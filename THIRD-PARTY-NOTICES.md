# Avisos de software de terceros

XHANNIZER0 utiliza y empaqueta bibliotecas de software libre y de código abierto. A continuación se reconocen las dependencias directas del proyecto y sus respectivas licencias:

| Paquete | Licencia | Sitio / Repositorio |
| --- | --- | --- |
| **Electron** | MIT | https://www.electronjs.org |
| **electron-updater** | MIT | https://github.com/electron-userland/electron-builder |
| **qrcode** | MIT | https://github.com/soldair/node-qrcode |
| **electron-builder** *(solo compilación)* | MIT | https://github.com/electron-userland/electron-builder |

Las dependencias transitivas de Node.js y Electron conservan sus propias licencias y avisos de copyright dentro de sus respectivos paquetes.

## Programas, drivers y marcas de terceros

- XHANNIZER0 no incluye ni redistribuye instaladores propietarios, juegos, BIOS ni firmware de terceros.
- Los programas del catálogo se instalan mediante **Windows Package Manager (`winget`)**, **Microsoft Store** o enlaces directos a las descargas oficiales de cada fabricante/proyecto.
- Todos los nombres de productos, logotipos y marcas mencionadas dentro de la aplicación (Microsoft, Windows, NVIDIA, AMD, Intel, ASUS, MSI, Gigabyte, ASRock, Steam, etc.) pertenecen a sus respectivos propietarios y se utilizan únicamente con fines descriptivos para identificar el hardware y software del usuario.
