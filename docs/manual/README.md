# XHANNIZER0 — Manual de usuario

**XHANNIZER0** es una aplicación gratuita y de código abierto de **Xhanni Studios** para dejar Windows 10 y Windows 11 listos después de formatear o armar un PC.

Reúne en un solo lugar lo que normalmente toma horas: detección real de drivers, instalación de programas oficiales, chequeo de BIOS y hardware, ajustes de Windows, limpieza, migración por USB y respaldos reversibles.

{% hint style="info" %}
XHANNIZER0 **no tiene cuentas, publicidad ni telemetría**. Antes de cambiar ajustes del sistema, crea un respaldo en tu equipo para que siempre puedas volver atrás.
{% endhint %}

## ¿Para quién es?

- **Personas que acaban de formatear o armar su PC** y quieren instalar drivers, programas y ajustes esenciales sin perder tiempo ni bajar instaladores dudosos.
- **Jugadores** que buscan verificar que su RAM (XMP/EXPO), monitor, Resizable BAR y Windows estén bien configurados.
- **Programadores, estudiantes y oficinas** que necesitan dejar el equipo ordenado y listo para trabajar en minutos.
- **Técnicos de soporte** que preparan equipos para clientes y quieren entregar un informe técnico en PDF con el antes y después.

## Requisitos

- **Sistema operativo:** Windows 10 o Windows 11 de **64 bits** (`x64`).
- **Conexión a internet:** necesaria para buscar drivers, instalar programas y comprobar actualizaciones.
- **Permisos de administrador:** opcionales para abrir la app, pero recomendados para aplicar ajustes del sistema, crear puntos de restauración o limpiar archivos de Windows sin avisos repetidos.

## Descarga oficial

Descarga siempre el instalador desde la página oficial de lanzamientos en GitHub:
