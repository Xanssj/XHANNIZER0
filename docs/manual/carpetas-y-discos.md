# Carpetas y discos

La sección **Carpetas y Discos** te muestra el espacio libre y usado de tus unidades, incluye utilidades rápidas para ordenar tu equipo tras formatear y concentra tu **Historial de Copias de Seguridad** y el **Kit USB Post-Formateo**.

<!-- captura: pantalla de Carpetas y Discos mostrando las unidades detectadas, las acciones rápidas y el Historial de Copias de Seguridad -->

## Acciones de carpetas y mantenimiento rápido

Todas estas acciones exigen respaldo previo obligatorio y nunca tocan carpetas críticas del sistema (`C:\Windows`, `Program Files` ni raíces de unidad):

1. **Crear estructura limpia de carpetas:** crea una estructura ordenada (`Proyectos`, `Juegos`, `Instaladores`, `Drivers_Oficiales`, `Documentos_Trabajo`) dentro de la carpeta o disco que elijas.
2. **Reordenar carpeta Descargas:** clasifica instaladores (`.exe`/`.msi`), archivos comprimidos (`.zip`/`.rar`/`.7z`), imágenes y documentos en subcarpetas limpias **sin borrar ningún archivo**.
3. **Limpiar temporales de instalación:** elimina restos temporales de instaladores y caché de XHANNIZER0 sin tocar sesiones activas ni archivos personales.
4. **Respaldo preventivo de drivers:** genera una instantánea verificada del inventario de drivers firmados y puede solicitar un punto de restauración antes de tocar nada.

## Crear Kit USB Post-Formateo

En la cabecera de **Historial de Copias de Seguridad**, el botón **Crear Kit USB Post-Formateo** prepara una carpeta o memoria USB lista para usar después de formatear, guardando tus respaldos y utilidades en la ruta que elijas.

1. Conecta tu memoria USB (o elige una carpeta de respaldo externa).
2. Haz clic en **Crear Kit USB Post-Formateo**.
3. Selecciona la carpeta destino y espera a que termine la copia.

{% hint style="info" %}
Desde esta misma pantalla también tienes el botón **Abrir carpeta de respaldos** para inspeccionar directamente `%USERPROFILE%\XhanniBackups\XHANNIZER0` y la lista completa del **Historial de Copias de Seguridad** con el botón **Deshacer cambios**. Consulta todos los detalles en [Deshacer cambios y respaldos](deshacer-y-respaldos.md).
{% endhint %}
